# نظام متابعة الأداء — عمر الياسي للعقارات (أندرويد)

تطبيق أندرويد يفتح نظام متابعة الأداء مباشرة. أي تعديل على النظام في Google Apps Script يظهر في التطبيق فوراً بدون تحديث.

## التحميل
كل تعديل يُرفع على الفرع `main` يبني نسخة جديدة تلقائياً. الملفات تظهر في **Releases**:
- `AlYassi-Performance-1.0.N.apk` — للتثبيت المباشر على الجوال.
- `AlYassi-Performance-1.0.N.aab` — للرفع على Google Play.

## ما يدعمه التطبيق
- رفع الملفات والصور (من المعرض أو الكاميرا).
- تحميل الملفات إلى مجلد التنزيلات.
- روابط الاتصال وواتساب والبريد والخرائط تفتح في تطبيقاتها.
- شاشة "لا يوجد اتصال" مع زر إعادة المحاولة.
- زر الرجوع يرجع للصفحة السابقة، وضغطتين للخروج.

## تغيير الرابط
لو تغيّر رابط النشر (`/exec`)، عدّله في `app/src/main/res/values/strings.xml` (السطر `app_url`) وارفع التعديل.

## مفتاح التوقيع
مفتاح توقيع التطبيق محفوظ في أسرار المستودع (Settings → Secrets → Actions) باسم `ANDROID_KEYSTORE_BASE64` و`ANDROID_KEYSTORE_PASSWORD` — وليس داخل الملفات. احتفظ بنسخة منه، فبدونه لا يمكن تحديث التطبيق.
